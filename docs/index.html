Overview

Core promise Veridex explains what a smart contract can actually do and makes the evidence behind that explanation inspectable.

The product separates deterministic contract analysis from presentation, monitoring and protocol transport. This lets the same evidence model power the web application and the Telegraph Miner.

Analysis model

The current H1 semantic analyzer accepts Ethereum mainnet targets. It validates the address, resolves proxy composition, obtains verification evidence and bytecode, observes ownership/state, and evaluates the supported capability set.

  • ownership
  • upgradeability
  • pause
  • mint

Results are normalized as positive, negative, inconclusive, unavailable or error. Confidence and conclusiveness are explicit fields.

Evidence hierarchy

Verified ABI/source evidence is stronger than selector heuristics. Instruction-boundary bytecode inspection is a fallback and does not manufacture certainty where selector collisions can exist.

verified ABI/source → instruction-aware bytecode fallback → inconclusive when evidence cannot support a conclusion

Proxy semantics

Veridex distinguishes the address holding live state from the address whose code is executed. A proxy can therefore be the queried contract while its implementation supplies ABI/bytecode evidence.

Beacon addresses are not treated as implementations without supported resolution. Nested proxy composition is bounded and cycle-aware.

Capability Passport

A Passport is a canonical observation record containing subject identity, observation time, evidence fingerprint, posture, capabilities, composition, verification and provider state.

veridex.capability-passport.v1

It is not a vulnerability score and does not invent historical state. Persistence belongs to the later production monitoring layer.

Watch

The domain model supports baselines, versioned observations, evidence-backed diffs and explicit inconclusive states. The current web surface intentionally uses a browser-local watchlist and manual checks; it does not claim a durable scheduler or deployed background alert service.

API

The application analysis endpoint accepts an Ethereum mainnet contract and returns the normalized result plus Capability Intelligence and Passport representations.

POST /api/analyze Content-Type: application/json {"chain":"1","contractAddress":"0x…"}

The production Miner response uses schema veridex.miner.v1.

Engineering principles

  • Evidence is stronger than narrative.
  • Uncertainty is a first-class state.
  • Provider failure never becomes a capability removal.
  • Code address and state address remain semantically distinct.
  • Animations should communicate real system state.
  • Historical measurements are not presented as current verification without fresh evidence.
