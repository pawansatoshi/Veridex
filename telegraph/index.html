Why the adapter is isolated

The analysis domain should remain useful to the web product, agents and future protocols even if Telegraph transport or evaluation changes.

The current API is an adapter around the same `minerDependencies.analyze` path used by the application-facing analysis surface.

Evidence policy

Historical H1 evaluation reported perfect scores and a successful historical live integration, but those measurements are deliberately not presented here as current-commit verification. The repository state requires fresh evidence before claiming current CI, live registry alignment, ranking, demand or traffic.

Current-main verification remains an explicit gate.

Veridex · Telegraph integration is a replaceable protocol adapter, not the product itself.
