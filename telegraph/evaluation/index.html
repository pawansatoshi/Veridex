Track 2 · Script Author / Evaluation

Measure the intelligence.

Veridex evaluates Miner behavior against reproducible ground truth. The evaluator is a quality gate, not a black-box marketing score.

Evaluation pipeline

Ground truth corpus→Live Miner→Expected vs observed→Deterministic evaluation

What is measured

  • Correctness / accuracy
  • Evidence coverage
  • Conclusive rate
  • False positives
  • False negatives
  • Provider / unavailable outcomes

Reproducibility

The repository provides a deterministic evaluator and ground-truth report. Results must be regenerated from the current code and corpus before being presented as current.

npm run evaluate:miner

Current measurement policy

Accuracy— until freshly measured
False positives— until freshly measured
False negatives— until freshly measured
Evidence coverage— until freshly measured
Conclusive rate— until freshly measured
Latency— until freshly benchmarked

Integrity boundary

Internal evaluation results are not Telegraph's official ranking. Veridex does not fabricate performance, traffic, demand or accuracy numbers.
