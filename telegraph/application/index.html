Why this is an application

  • It is a public production interface, not a mock dashboard.
  • Each run calls the Track 3 endpoint and attempts a live Telegraph Engine request.
  • Miner/provider, intent, response, and payment state are exposed when available.
  • Deterministic evidence stays separate from external intelligence.
  • Conflicting intelligence remains a conflict instead of becoming false certainty.

For users

For agents
