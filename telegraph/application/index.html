Why this qualifies as an application

  • It is a public production interface, not a mock dashboard.
  • Each run calls the real Track 3 endpoint and attempts a real Telegraph Engine request.
  • The Miner/provider, intent, response and payment settlement state are exposed when available.
  • Deterministic evidence remains separate from external intelligence, so outages or malformed provider output cannot manufacture a finding.
  • Conflicting intelligence is retained as conflict instead of being flattened into false certainty.

For users

Paste a contract and inspect the exact evidence behind ownership, upgradeability, pause and mint observations before acting.

For agents

The endpoint returns structured deterministic analysis, Telegraph provenance and a machine-readable decision state suitable for bounded downstream workflows.
