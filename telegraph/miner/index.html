Capabilities

  • Ownership / control

Failure semantics

  • Conclusive
  • Inconclusive
  • Unavailable
  • Provider / infrastructure failure

Evidence hierarchy

Verified ABI/source is preferred. Structural evidence is used where legitimately supported. Bytecode fallback remains instruction-boundary aware and is never treated as authoritative semantic proof.

Provider or application failure is never silently translated into a negative or safe finding.
